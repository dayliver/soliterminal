# soliterminal

**터미널에서 키보드만으로 즐기는 클론다이크 솔리테어.**
모든 판은 이길 수 있고, 이길 수 없게 되는 순간 내장 솔버가 알려 주며,
언제 자리를 떠도 게임은 그대로 기다립니다.

[English](README.md)

## 만든 이유

개발자의 하루 중 AI 에이전트에게 일을 맡기고 끝나기를 기다리는 시간이 점점
늘고 있습니다. 다른 일을 시작하기엔 짧고, 흘러가는 로그만 보고 있기엔 긴
시간입니다. soliterminal은 그 시간을 위해 만들었습니다. 이미 열려 있는 터미널에서
한 판 하다가, 에이전트가 부르면 바로 멈추고, 나중에 멈춘 자리에서 그대로 이어 가면
됩니다.

## 특징

- **더미가 있는 자리에 키가 있습니다.** 각 더미 위에 표시된 키는 키보드에서도 같은
  자리에 있습니다. 보드 윗줄은 키보드 윗줄(덱 `q`, 버린 카드 더미 `w`, 파운데이션
  `r`~`u`), 일곱 줄은 바로 아래 가운뎃줄(`a`~`j`)입니다. 펑션 키를 쓰지 않으니
  어느 터미널, 노트북, 에디터에서나 똑같이 동작합니다. 화살표 키도 쓸 수 있습니다.
- **모든 판은 이길 수 있습니다.** 새 판을 보여 주기 전에 솔버가 이길 수 있는 판인지
  증명합니다.
- **졌다는 걸 바로 알려 줍니다.** 헤더에 지금 상황에서 아직 이길 수 있는지가 수마다
  표시됩니다. 지는 수를 두면 바로 알려 주고, `z`로 그 수를 무를 수 있습니다.
- **실수하기 전에 경고합니다.** 생각하는 동안 솔버가 한 수 앞을 살펴봅니다. 집은
  카드를 놓을 자리 중 지는 곳이 있으면, 어디인지는 말하지 않고 조심하라고 알려
  줍니다. 남은 리딜을 모두 써야만 이길 수 있는 상황이 되면 헤더에도 표시됩니다.
- **게임은 저장됩니다.** 언제 종료해도 다음 실행 때 판, 되돌리기 기록, 시계가 그대로
  이어집니다. 다른 창에 가 있는 동안은 시계도 멈춥니다.
- **모든 판을 기록합니다.** 판마다 시드와 함께 승패, 시간, 수, 진 수, 난이도가
  남습니다. 예전 판을 다시 하거나 시드를 직접 입력할 수 있습니다.
- **터미널 테마를 따릅니다.** 카드를 뺀 모든 색은 터미널의 16색 팔레트에서 고른 한
  가지 색 계열을 씁니다. 큰 카드와 작은 카드, 순수 ASCII 모드와 무색 모드도 있습니다.

## 설치

[Node.js](https://nodejs.org) 20 이상이 필요합니다.

```sh
npm install -g soliterminal
soliterminal
```

설치 없이 바로 해 보려면:

```sh
npx soliterminal
```

## 하는 법

클론다이크를 한 문단으로: 네 개의 파운데이션에 무늬별로 A부터 K까지 쌓으면
이깁니다. 일곱 줄에는 색을 번갈아 가며 한 단계씩 낮은 카드를 놓고(검은 7 위에 빨간
6), 빈 줄에는 K만 놓을 수 있습니다. 뒤집힌 카드는 위가 비면 앞면이 됩니다. 막히면
덱에서 카드를 넘기세요.

### 카드 옮기기

카드를 **가져올** 더미의 키를 누르고, **놓을** 더미의 키를 누릅니다. `f` 다음 `g`를
누르면 4번 줄의 카드가 5번 줄로 갑니다. 몇 장을 옮길지는 놓는 자리에 맞춰
정해집니다. 같은 키를 두 번(`f` `f`) 누르면 가장 알맞은 자리로 가고, 파운데이션에
갈 수 있으면 파운데이션으로 갑니다.

| 키 | 더미 |
|---|---|
| `q` | 덱에서 카드 넘기기. 덱이 비면 버린 카드 더미를 다시 뒤집기(리딜) |
| `w` | 버린 카드 더미 |
| `a` `s` `d` `f` `g` `h` `j` | 1~7번 줄 |
| `i` | 그 카드에 맞는 파운데이션. 카드를 올릴 때는 보통 이것을 씁니다 |
| `r` `t` `y` `u` | 특정 파운데이션 |

키는 위아래 더미끼리 키보드에서도 위아래에 있습니다. `q`는 `a` 위, `w`는 `s` 위,
`r`은 `f` 위인 식입니다. `e`는 보드 윗줄이 비어 있는 3번 줄 위라서 아무 일도 하지
않습니다. 파운데이션은 무늬가 정해져 있지 않습니다. A는 비어 있는 어느
파운데이션에나 놓을 수 있고, `i`를 쓰면 알맞은 곳을 골라 줍니다. 모든 카드가 앞면이
되면 게임이 알아서 마무리합니다.

키 배치는 미국식(QWERTY) 자판 기준입니다. 다른 자판에서는 같은 글자가 다른 자리에
있고, 화살표 키는 어디서나 그대로 쓸 수 있습니다.

### 커서

더미 키 대신 가리키는 방식이 편하다면:

| 키 | 동작 |
|---|---|
| `←` `→` | 같은 줄 안에서 이동 |
| `↑` `↓` | 바로 위나 아래 더미로 이동(1번 줄↔덱, 2·3번 줄↔버린 카드 더미, 4~7번 줄↔파운데이션) |
| 줄에서 `↓` | 옮길 장수 고르기. 커서가 연속된 카드 맨 위(예: K)로 들어가고, 누를 때마다 한 장씩 아래로 내려갑니다(Q, J, …). 고른 카드는 색이 칠해지고, 그 아래 카드와 함께 옮겨집니다. `↑`로 되돌립니다 |
| `Space` | 커서 자리에서 집기 / 놓기. 덱에서는 카드 넘기기 |
| `Enter` | 커서의 카드를 가장 알맞은 자리로. 커서는 카드가 떠난 자리에 남아, 거기서 뒤집힌 카드를 가리킵니다 |
| `Esc` | 집은 카드 내려놓기. 집은 카드가 없으면 메뉴 열기 |

### 키와 메뉴

| 키 | 동작 |
|---|---|
| `z` | 되돌리기. 처음 배치까지 돌아갈 수 있습니다(`Backspace`도 같음) |
| `Tab` | 큰 카드 / 작은 카드 전환 |
| `?` (또는 `/`) | 힌트. 먼저 묻고, 솔버의 다음 수를 바로 보여 줍니다([힌트](#힌트) 참고) |
| `Esc` | 메뉴 |
| `x` | 종료 (먼저 묻습니다. 게임은 저장됩니다) |
| `Ctrl+Q` | 바로 종료. 이때도 게임은 저장됩니다(`Ctrl+C`도 같음) |

나머지는 모두 메뉴에 있습니다. 괄호 속 글자(`(N)ew game`의 `n`)를 누르면 바로 실행되고,
`↑` `↓`로 고른 뒤 `Enter`(또는 `Space`)로 실행해도 됩니다. `Esc`로 닫습니다. 게임 중에 뜨는 다른 질문도 모두 같은 방식입니다.

| 메뉴 | 동작 |
|---|---|
| New game | 새 판 (진행 중이면 먼저 묻습니다. 포기하면 진 판으로 기록) |
| Restart this deal | 이 판 처음부터 다시 (먼저 묻습니다. 이긴 판은 안 됨) |
| Draw 3 / Draw 1 instead | 손대지 않은 판이면 바로, 아니면 다음 판부터 |
| Hint | `?`와 같음 |
| Play a seed or a recent game | 시드 입력, 또는 지난 판 중에서 고르기 |
| Statistics | 넘기는 방식별 기록 |
| Keys and rules | 키 안내 |
| Quit | 종료. 게임은 저장됩니다 |

이긴 뒤 결과 창에도 Quit이 있고, 이때는 다음 실행 때 새 판이 시작됩니다. `Win 0%`
선택지에도 Quit이 있으며, 이때는 게임이 저장됩니다.

리딜은 기본 세 번까지 할 수 있습니다(`--redeals`로 변경). 남은 횟수는 덱 바로 아래에
항상 표시됩니다(`↺2`, 다 쓰면 빨간 `↺0`).

## 솔버와 함께 하기

### 헤더

헤더는 지금 상황을 늘 알려 줍니다.

| 헤더 | 뜻 |
|---|---|
| `Win ✓` | 아직 이길 수 있음 |
| `Win ✓!` | 이길 수 있지만 남은 리딜을 모두 써야 함. 덱을 헛돌릴 여유가 없음 |
| `Win ⚠` | 손에 든 카드를 놓을 수 있는 자리 중 지는 곳이 있음 |
| `Win …` | 확인 중 (보통 1초도 안 걸립니다) |
| `Win ?` | 아직 판정하지 못함. 백그라운드에서 더 오래 살펴보는 중 |
| `Win 0%` | 더 이상 이길 수 없음 |

`Win 0%`가 되면 마지막으로 이길 수 있던 상황으로 돌아가기(`z`로도 됨), 이 판
처음부터 다시, 새 판, 계속하기(`Esc`) 중에서 고릅니다. 몇 수 전에 이미 진
판이었다면 대화 상자가 몇 수 전인지 알려 주고, 돌아가기는 그 직전으로 갑니다.

### 경고

생각하는 동안 솔버는 한 수 뒤의 모든 상황을 살펴봅니다. 집은 카드를 놓을 수 있는
자리 중 지는 곳이 있으면 메시지 줄이 빨갛게 바뀝니다.
`⚠ Careful: one of its two places loses the game.` 어디인지는 말하지 않습니다.
고르는 건 여전히 플레이어의 몫입니다. 그래도 그 자리에 놓으면 바로 `Win 0%`가 되고,
`z`는 정확히 그 한 수만 무릅니다.

솔버가 판정한 상황은 그 판이 끝날 때까지(처음부터 다시 해도) 기억하므로, 한 번 한
실수는 다음에 기다림 없이 바로 잡아냅니다.

### 힌트

솔버는 뒤집힌 카드까지 보기 때문에, 플레이어 눈에는 안 보이는 이기는 수를 알고 있을
수 있습니다. 줄의 일부만 옮기기나 파운데이션에서 카드를 다시 내리기 같은 수입니다.
`?`는 언제든 횟수 제한 없이 쓸 수 있습니다. 한 번 묻고 나서 이기는 쪽으로 가는 솔버의
다음 수를 보여 줍니다. 솔버가 아직 판정 중이거나 이 자리에서 이길 수 있는지 확인되지
않았으면 그렇다고 알려 줍니다. 카드를 하나도 옮기지 않고 덱을 한 바퀴 다 돌리면(또는
더 넘길 카드가 없는데 `q`를 누르면) 둘 수가 있다고 먼저 알려 줍니다.

## 내 게임

### 두는 대로 저장

언제든 종료하세요. 다음에 `soliterminal`을 실행하면 같은 판이 되돌리기 기록 전부,
시계와 함께 이어집니다. 끝난 판만 저장하지 않습니다. 종료할 때 그 판의 시드가
출력됩니다.

시계는 게임 터미널에 포커스가 있을 때만 가므로, 에이전트와 일하는 시간은 기록에
들어가지 않습니다. 대부분의 터미널이 포커스 변화를 알려 줍니다(kitty, WezTerm,
iTerm2, Windows Terminal, GNOME Terminal, Konsole). tmux에서는
`set -g focus-events on`을 켜세요. 알림이 오지 않는 터미널에서는 시계가 평소처럼
갑니다.

저장되는 게임은 하나입니다. 다른 창에서 soliterminal을 하나 더 띄우면 같은 게임을
이어받고, 마지막에 저장한 창의 게임이 남습니다. 두 창에서 같은 판을 끝내도 한
번만 셉니다.

### 통계

모든 판은 시드와 함께 기록되고, 통계는 이 기록에서 Draw 1과 Draw 3을 따로
계산합니다. 판 수, 승리, 승률, 현재 연승과 최장 연승, 최단 시간, 최소 수가 나옵니다.

판은 끝났을 때 기록됩니다. 이겼을 때, 또는 끝내지 않고 다른 판으로 넘어갔을 때(진
판으로 기록되고 연승이 끊깁니다)입니다. 덱만 넘겨 본 판은 판으로 치지 않습니다.
같은 판을 처음부터 다시 해도 같은 판이 이어지는 것으로 보고, 종료는 잠시 멈추는
것일 뿐입니다. 여러 창에서 동시에 해도 됩니다. 끝난 판은 기록 파일에 한 줄씩
덧붙여지므로 서로 덮어쓰지 않습니다.

### 판 고르기

메뉴의 Play a seed or a recent game을 고르면 지난 판이 최근 것부터 나옵니다.

```
 soliterminal · Deals

   Seed                 Draw 1  (← → switches)

   Your games
     Seed        Draw  Result     Time   Moves  Redeals Level   When
   › 707746170   1     lost @86   06:40     86          hard    11-25 15:07
     109483114   1     won        06:52    131    2             11-25 13:40
     46732994    1     gave up    12:10     36          medium  11-25 11:50
     3291647763  3     won        03:05     98    0             11-24 18:03

 Type a seed, or choose a game with ↑ ↓. Enter plays it; esc goes back.
 Playing another deal gives up seed 2902541007: it counts as a loss.
```

화살표로 고르고 `Enter`를 누르면 그 판을 다시 합니다. 아무 시드나 입력해도
됩니다(`←` `→`로 Draw 1/3 전환). 입력한 시드는 미리 확인하지 않으니, 솔버가 판정을
마치면 헤더에 표시됩니다.

- **Result.** `lost @86`은 86수째(헤더의 Moves와 같은 기준)에 이길 수 없게 됐다는
  뜻입니다. `gave up`은 아직 이길 수 있었을지도 모르는 상태에서 그만둔 판, `no win`은
  처음 배치부터 이길 수 없던 판입니다.
- **Redeals.** 이긴 판에서 버린 카드 더미를 다시 뒤집은 횟수입니다.
- **Level.** 진 판은 백그라운드의 남는 스레드에서 몇 초 동안 난이도를 매깁니다.
  솔버가 이기는 수순을 따라가며 지는 수가 섞인 지점과 이기는 수가 하나뿐인 지점을
  셉니다. `easy`, `medium`, `hard`로 표시되고, 계산 중에는 `…`가 나옵니다.

이긴 판은 다시 나오지 않고, 같은 넘기는 방식으로는 다시 고를 수도 없습니다. 예전에
진 판이 다시 나오면 언제 졌는지 알려 주고, 상태 표시줄 위 줄에도
`lost before 11-25 15:07`처럼 계속 표시됩니다.

### 결과 공유

자동으로 나가는 데이터는 없습니다. 끝낸 판이 100판이 되면, 그리고 200판, 300판마다
한 번씩, 판을 이긴 직후 결과를 보여 주기 전에 클론다이크 연구 자료로 보낼지 묻습니다.
게임 도중이나 새 판을 시작할 때는 묻지 않습니다. 거절하면(`Esc`) 다음
백 판에서 다시 묻고, 그때 동의하면(`Enter`) 아직 보내지 않은 판을 한 번에 1,000판까지
보냅니다. 더 작은 묶음으로 보내는 방법은 없습니다. 모두가 한두 판씩 수시로 보내면
서버만 괜히 바빠지기 때문입니다.

판마다 보내는 것은 시드, 넘기는 방식, 리딜 제한, 승패, 시간, 수, 쓴 리딜 수(이긴 판),
진 수와 난이도(진 판), 플레이한 날짜, 그리고 판마다 무작위로 붙인 이름입니다. 그
밖에는 같은 판이 두 번 들어가도 한 번만 세도록 내 컴퓨터에서 무작위로 만든 설치 이름
하나와 soliterminal 버전만 보냅니다. 이름, 계정, 주소, 파일 경로, 시각은 보내지
않습니다. 서버 코드는 [`server/`](https://github.com/dayliver/soliterminal/tree/main/server)에 있고,
설명은 [DEVELOPMENT.md](DEVELOPMENT.md#share-server)에 있습니다.

## 옵션

```sh
soliterminal --draw 3 --theme blue
```

| 옵션 | 뜻 |
|---|---|
| `--draw 1\|3` | 한 번에 한 장 또는 세 장 넘기기 (기본 1) |
| `--redeals N` | 버린 카드 더미를 다시 뒤집는 횟수: 0~99 또는 `unlimited` (기본 3). 풀 수 있는 판인지도 같은 제한으로 확인합니다 |
| `--compact` | 작은 카드로 시작 |
| `--theme NAME` | 색 계열: `green`(기본), `cyan`, `blue`, `magenta`, `yellow`, `red`, `white` |
| `--seed N` | 특정 판으로 시작, 0~4294967295 (미리 확인하지 않음). 진행 중인 게임이 저장돼 있으면 이어서 할지, 포기하고(진 판으로 기록) 시작할지 묻습니다 |
| `--any-deal` | 풀 수 있는 판만이 아니라 아무 판이나 |
| `--ascii` | ASCII 문자만 사용: 선 문자, 무늬 기호, 이모지 없음 |
| `-h`, `--help` | 사용법 보기 |

| 환경 변수 | 뜻 |
|---|---|
| `SOLITERMINAL_THEME=NAME` | `--theme`과 같음 (옵션이 우선) |
| `SOLITERMINAL_CARD=ddd\|fff` | 카드 바탕: 부드러운 회백색(기본) 또는 순백색 |
| `SOLITERMINAL_STATS=PATH` | 판 기록과 통계 파일 (한 판에 한 줄인 기록) |
| `SOLITERMINAL_GAME=PATH` | 진행 중인 게임 파일 (기본: 통계 파일 옆의 `current.json`) |
| `SOLITERMINAL_SHARE_URL=URL` | 공유한 결과를 받을 주소 (공유 서버 시험용) |
| `COLORTERM=truecolor` | 카드 색을 정확하게 (아니면 가장 가까운 256색) |
| `NO_COLOR=1` | 색 없음 |

데이터는 `~/.local/state/soliterminal/`(`$XDG_STATE_HOME`이 있으면 그 아래), Windows는
`%LOCALAPPDATA%\soliterminal\`에 있습니다. `games.jsonl`에 판 기록이 한 줄에 한
판씩, `current.json`에 진행 중인 게임이, `share.json`에 공유 상태가 들어 있습니다.
예전 버전의 `stats.json`은 처음 실행할 때 `games.jsonl`로 옮겨지고, 원래 파일은 그대로
남습니다.

## 터미널

- **크기.** 가로 56칸 이상. 세로는 맞춰집니다. 공간이 모자라면 뒤집힌 카드 더미가 한
  줄로 접힙니다.
- **큰 카드**는 무늬를 이모지로 그리므로 이모지를 그리는 터미널과 글꼴이 필요합니다.
  예를 들어 kitty, WezTerm, Ghostty, iTerm2, Windows Terminal. 그 밖의 터미널에서는
  무늬가 작게 보이니, 어디서나 제대로 보이는 작은 카드(`Tab`)를 쓰세요.
- **색.** 화면은 터미널의 16색 팔레트를 쓰므로 밝은 테마든 어두운 테마든 잘
  어울립니다. 카드만 고정된 색을 씁니다.

## 개발

```sh
npm install      # 타입 검사용 TypeScript와 Node 타입
npm start        # 소스에서 바로 실행 (Node 22.18+는 .ts 파일을 그대로 실행)
npm run check    # 타입 검사와 테스트
npm run build    # npm 패키지용으로 dist/에 컴파일
npm run preview  # 정지 화면 한 장 출력
npm run peek     # 진행 중인 게임과 아직 이길 수 있는지 보기
```

실행에 필요한 의존성은 없습니다. 코드 구조와 설계 결정, 공유 서버, 남은 과제는
[DEVELOPMENT.md](DEVELOPMENT.md)(영어)에 정리해 두었습니다.
